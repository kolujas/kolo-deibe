    ¿Borrarlo para siempre?

    Para publicar, esta página usa una clave de GitHub que queda guardada solo en este navegador. Quien no la tenga, solo puede leer.

    1. Abrí crear una clave en GitHub.
    2. En Repository access elegí Only select repositories y marcá kolo-deibe.
    3. En Permissions → Contents, poné Read and write.
    4. Elegí cuánto dura, generala, copiala y pegala acá abajo.
